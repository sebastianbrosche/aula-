# aula

aula is for one class. You should not have to learn it, and you should not have to open it.

Ask Google Home, Alexa, or Grok: what is school tomorrow, what do they bring, is there an excursion, did the road close. Teachers post photos and videos of the day. That feed is simple. The point is the assistant already knows.

The first apps you open are **iOS and Android**. The server of truth is a Cloudflare API (Hono, MCP). A public landing page invites schools that want to try. Free for schools. They help by using it, filing bugs, and asking for what is missing.

Quiet by default. Privacy switches on nearly everything. If you want to help (wishes, a birthday group), you opt in. If you want to be left alone, that works too. YOLO mode is an optional standing yes for excursions and photos so we stop pinging you.

No points. No Plus. Children do not log in.

Ship a tryable app, put the landing up, learn from real classes. Do not wait for a school-year deadline.

**aula - a sala do grupo, fora do WhatsApp.**

# aula

aula é para uma turma. Não deves ter de a aprender, nem de a abrir.

Pergunta ao Google Home, à Alexa ou ao Grok: o que é a escola amanhã, o que levar, se há visita de estudo, se a estrada fechou. Os professores publicam fotos e vídeos do dia. Esse mural é simples. O ponto é o assistente já saber.

As primeiras apps são **iOS e Android**. O servidor é uma API na Cloudflare (Hono, MCP). Há uma página pública para escolas que queiram experimentar. É grátis. As escolas ajudam ao usar, ao reportar falhas e ao pedir o que falta.

Calma por defeito. Interruptores de privacidade em quase tudo. Se quiseres ajudar, entras. Se quiseres ser pouco envolvido, também dá. O modo YOLO é um sim permanente opcional para visitas e fotos, para deixarmos de incomodar.

Sem pontos. Sem Plus. As crianças não entram.

Lançar uma app que se possa experimentar, pôr a página no ar, aprender com turmas reais. Não esperar por um prazo do calendário escolar.

**aula - a sala do grupo, fora do WhatsApp.**
