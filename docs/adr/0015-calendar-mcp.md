# ADR-0015: calendar feed and AI connector

- Status: accepted
- Date: 2026-09-08

## Decision

Parents should not have to open aula to stay current.

1. **ICS feed** per parent, signed URL, same visibility as the app. Subscribe in Google Calendar (or any calendar). Birthdays, dated announcements, events. Free.
2. **Read API + MCP** with the parent's session or a personal token. Tools like: week summary, story since date, birthdays this week, unread announcements. Visibility rules apply. Write is out of v1.

Not a Google login. Not a Plus upsell. Not a custom calendar UI we have to staff.

## Why

Show the children the photos from school. Ask an agent what happened this week. Get birthday reminders in the calendar you already use.
